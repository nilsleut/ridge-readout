# Claims ledger

Every number below has a macro in `paper/numbers.tex` (generated by
`scripts/export_macros.py` from `results/`). Values are shown as the macro renders them,
for reading convenience; the macro is the source. CIs are 95% stimulus-bootstrap
percentile intervals (1000 paired resamples). Sign conventions:
- own CNN: V1 = Random − Backprop, LOC = Backprop − Random;
- ImageNet models: V1 = untrained − trained, LOC = trained − untrained.

**"Criterion fixed before the analysis"** means, in every row below, that the commit
adding the amendment with the criterion precedes the commit adding the first script
that computes it. The commit hashes and timestamps are given as evidence. There is no
public registration.

component.

|---|---|
| Rules and thresholds | R3 (step 5): S_z ≤ 0.5 · S_raw. O2 (step 7): a strong slope (CI above 0 and S ≥ 0.5 · S_paper) only in uncentred correlation/cosine cells with B = paper; at most 2 violations among 36 cells. P_ridge (step 6): ridge Random − BP ≤ 0 at all six resolutions and S_ridge ≤ 0.5 · S_raw. |
| Result, own CNN | S_raw +0.031 [0.024, 0.038] (`\SlopeRaw`, `Lo`, `Hi`); S_z +0.002 [−0.004, 0.007] (`\SlopeZ`, `Lo`, `Hi`); O2 violations 0 (`\MultiOTwoViolations`); paper-cell slope +0.031 [0.024, 0.038] (`\MultiSlopePaper`, `Lo`, `Hi`); S_ridge −0.000 (`\PRidgeSlope`) |
| Result, ImageNet (descriptive, step 9 point b) | V1 angle slope 224 → 448 with CI above 0 in 4 of 5 models (`\SepSlopeAngleCiPositive`), e.g. resnet50 +0.010 [0.007, 0.014] (`\SepSlopeResnetfiftyAngleCenter`, `Lo`, `Hi`). No norm slope has a CI excluding 0 (`\SepSlope<Model>NormCenter`, `Lo`, `Hi`). |
| Verdict | R3, O2 and P_ridge met for the own CNN. GEN4 (offset-specificity of the ImageNet slope) not met, see below. The ImageNet part is descriptive. |
| Macros | `\SlopeRaw[Lo/Hi]`, `\SlopeZ[Lo/Hi]`, `\MultiOTwoViolations`, `\MultiSlopePaper[Lo/Hi]`, `\PRidgeSlope`, `\SepSlopeAngleCiPositive`, `\SepSlope<Model>AngleCenter[Lo/Hi]`, `\SepSlope<Model>NormCenter[Lo/Hi]` |
| Figures | `fig:sign_flip`, `fig:multiverse_v1` (panel S), `fig:separation` (right panel) |
